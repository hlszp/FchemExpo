## 3. AI 分析洞察（每页必须有）

### 3.1 位置

1. **顶栏“AI 分析”按钮**（所有页面）；
2. **页内 AI 卡片**（每页底部，显示一句话结论 + 2–3 个 chips）；
3. 点击任一入口 → 右侧 **AI 分析抽屉**。

### 3.2 抽屉结构

- 元信息：演示模式 / 生成时间 / 依据（当前筛选、当前页面）；
- 一句话结论；
- 关键发现（3 条，带具体对象/数字）；
- 建议动作（3 条，按优先级编号）；
- 依据 chips；
- 底部“重新生成”：模拟 0.9 秒计算，刷新时间并 toast；
- 明确声明：基于演示数据，仅用于演示，不替代专业判断。

### 3.3 交互要求

- 筛选/切换页面后，AI 结论必须跟着当前页面与筛选变化；
- 数字与表格/图表同源，不能写死与页面矛盾；
- 无真实 LLM 调用、无账号口令、无外部请求；这是“演示 AI”。
