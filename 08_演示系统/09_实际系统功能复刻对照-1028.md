### 2. 电子批记录：实际结构与复刻

实际页面：
- 列表：UP 批次编号、产品名称、工单号、配方编号、产量、收率、审核状态、审核人、审核时间、实际结束时间、操作；顶部按批次/产品/配方筛选；共 2,825 条、10 条/页。
- 详情：返回列表、批次标题、产品、审核状态、审核、PDF/打印；
- 左侧：工单卡片 + 单元/OP 导航（SH 缩合、FS-1 分水、JW-1 降温、LV-1 氯化、YL-1/2 压滤、FC-1 分层、CQ-1 萃取、TS-1 脱色、SUH-1 酸化、LX-1 离心）；
- 右侧：电子批生产记录抬头；批次头（批次/产品/状态/标准时长/实际时长/执行时间/产量/收率/总产量/审核状态/审核人/审核时间/审核备注）；
- 每个单元：单元行 + OP 行（名称/执行时间/标准时长/实际时长/操作）；
- OP 展开：过程参数表（记录时间 + 电流/物料/搅拌/压力/步序/温度等，含位号、均值/最小/最大、30 分钟/1 小时切换）；
- 单元/批记录级：产量、质量（检验状态/判定/等级/检验人/时间/审核人/时间）、投料量、中间产品、化验记录（最终一次）、UP 趋势图；

## 二、iPAE 过程分析与探索系统

- 数据与配置：数据导入 / 位号管理 / 设备分组 / 就绪度体检 / 趋势组 / 快照；
- 系统：用户与角色 / 审批队列 / 审计日志。

## 五、跨系统事实（仿真下一阶段）

实际产品是打通的：
- iCLPM 右上角「进入工作台」→ inWork；
- iMCS 驾驶舱与生产监视大屏共用实时数据（七类公用工程）；
- inWork 定时任务每天 08:00 调 iAAS 数据做报警六项率统计；
- inWork 事件来源含视频分析/人工登记/随手拍。

高仿真已加入“同批号贯穿”浮层和全链路任务指挥台 /demo/app/chain/：LX-BIT-2610136A1 从 iPAE 批次异常 → iAAS 报警 → iCLPM 回路 → iMCS eBR → inWork 处置；另有催化剂活性、换热器性能两个慢变量任务。跨系统是演示映射，目标页显示贯穿上下文条。

导演模式已上线（/demo/app/scenarios/）：5 个精细化工异常场景，每个 6–8 幕，底部导演条跨 iAAS/iPAE/iCLPM/iACMS/iMCS/inWork 翻页；状态持久化，可重置。P1–P4：5 个独立 iACMS case、文本上传真实读取、Agent trace/置信度/人工确认、全屏/自检/重置、数据口径说明。

iACMS 已独立上线（/demo/app/iacms/）：6 页覆盖文档入库→异常工况库→多系统识别→Agent 任务链→推演→复盘；AI 抽取与任务链为演示级，真实文档解析/OCR、系统接口和自动制动边界待接。

iLINK 已做成 inWork mini app：/demo/app/inwork/ 为 inWork 应用概览预览（8 个应用，iLINK 卡片 + iframe），嵌入入口 /demo/app/chain/?embed=inwork，清单 chain/inwork-app.json；真实 inWork 侧只需注册 iframe 应用，本次未修改线上 inWork 五个应用。

AI 助手支持自然语言多轮对话：顶栏“AI 助手”打开对话，AI 卡打开分析洞察；上下文包含当前页面可见数据、页面结论与跨系统链路。Base URL/API Key 可在 /demo/app/ai-config/ 或任意 AI 设置中配置；无 Key 时保持演示规则。
