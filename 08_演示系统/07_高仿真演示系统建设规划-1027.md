## 2. 为什么不能继续做“导览”

现有 03_高仿真原型 是 9 幕图片+数字+讲点，属于“导览”，不是软件。  
用户要的是：**打开就是软件界面，能点导航、切筛选、点表格行、图表联动、弹详情、模拟提交**。  
所以第二阶段按“软件本体仿真”做，导览只保留为 3 分钟辅助。

## 3. 总体架构

- 纯静态：HTML/CSS/JS，无后端、无数据库、无账号；
- 每个产品一个独立应用目录：/demo/app/ipae/、/demo/app/iaas/、……；
- 共享：/demo/app/_shared/（顶栏、侧栏、图表、弹窗、数据工具）；
- 数据：本地 JSON/JS 合成数据，按“演示场景”组织；
- 路由：hash 或 query（#batch、#alarm、#loop），刷新可回到当前页；
- 图表：本地 Chart.js/ECharts（不引 CDN）；
- 响应式：1920×1080 为主，1440/390 不横向溢出；
- 安全：无真实客户名、无账号口令、无生产数据、无内部链接。

      iaas:  { real: "http://221.226.3.250:82/",    sim: "/demo/app/iaas/" },

- sim 为空：卡片指向 real；

- 页面地址不变，只改配置。

- [ ] 数据前后一致（筛选后数字/图表跟着变）；
- [ ] 1440×900、1920×1080、390×844 无横向溢出；
- [ ] 0 console error / 0 pageerror；
- [ ] 无客户名、无账号口令、无生产数据、无内部链接；
- [ ] 首屏 < 3s（本地/公网）。
