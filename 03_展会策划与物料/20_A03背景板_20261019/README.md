# 精细化工背景板 · 产品架构与四级爬坡

## 第三版设计与文件

一行主标语「让装置数据，变成企业的生产力」。以 iIoTS 数据底座托起四级产品能力，用同一张阶梯架构图说明产品应用和演进方法。

| 层级 | 产品与能力 | 方法 |
|---|---|---|
| L0 数据底座 | iIoTS，工业数据采集与集成 | 把数据接上来 |
| L1 装置体检 | iAAS + iCLPM，报警治理与回路诊断 | 把异常确诊 |
| L2 批次语义 | iPAE，轨迹对比与批次分析 | 把时序变语义 |
| L3 任务协同 | inWork，工业智能工作台，规划中 | 把洞察变任务 |
| L4 生产执行 | iMCS，配方、物料、质量、追溯 | 把结论变执行 |

图示表达产品能力定位与四级爬坡方法，不表示产品间集成已经完成，也不表示客户必须按固定顺序采购。沿用委托书的产品层级，未添加收益数字或自动控制承诺。

- 取消苯环、含氟和分子结构装饰；精细化工定位通过批次、配方、物料、质量和追溯表达。
- 取消「黄金批次」主标题和独立轨迹主图，相关意图收进 iPAE 的轨迹对比与批次分析能力。
- 主标语改为一行；阶梯实体、青蓝边缘和逐级增强的蓝色承担主视觉。
- 质量、效率、成本作为价值主张保留；inWork 明确标注「规划中」。
- 所有正文、图形和二维码位于上方 1200 mm 内，底部 900 mm 留空；板面无 A03。
- 品牌 LOGO 保持原件，二维码继续指向 `http://www.zlinfot.com`。

本版按用户最新要求调整；与 `19_背景板设计任务委托书.md` 中原先的两行标题、抽象主视觉要求不同时，以本次明确修改意见为准。

- 第三版另行检查：无 A03、黄金批次标题及旧分子图形标识；正文基线不得超过距板顶 1190 mm。

![正面效果图](A03-effect-1920.jpg)

## 设计

深藏青满版底色，两行主标语占据视线黄金区。主视觉以分散的过程曲线汇聚成紧密包络，呼应从装置数据到批次语义的主线。六条产品线集中排在一条横带，二维码保持在便于扫描的高度。

- 主标语：让装置数据 / 变成企业的生产力。
- 副标题：从批次管理入手 · 一条基于现有 DCS 数据的四级爬坡路径。
- 原始 LOGO、二维码按字节复用；主视觉用内置 imagegen 形成构图概念，再绘制为可编辑 SVG 贝塞尔曲线。
- 页面分为品牌、主张、主视觉、二维码、产品线、联系方式六个信息区。
- 未使用客户界面截图、案例数字、坐标图或旧产品代号。

需要 Node.js 和 `sharp@0.35.5`。本轮使用 macOS 的 PingFang SC 字体；其他机器需提供同字体以保持排版一致。SVG 自带图形素材，不依赖外部图片路径。

```bash
npm install
npm run build
```

也可通过 `A03_SHARP_MODULE` 指向已有的 sharp 包目录，免安装重建。
